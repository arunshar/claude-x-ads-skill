# Changelog

## 0.1.0 (November 2026)

This is the first public version.

- It adds the `x-ads-campaign` skill, which covers the preflight, the draft, the paused build, the readback, the spend card, the exact `yes, launch` approval, monitoring, live changes and wrap-up.
- It adds the setup reference for the X Developer Console app, the ads account, `claude mcp add` and OAuth scopes.
- It adds the tutorial in `docs/` and a case study of a real first run.

## Tested with

| Component | Version or date |
| :- | :- |
| Claude Code | 2.1.332 |
| X Ads MCP server | as served in November 2026 |
| X Ads API | v12 routes, per X's MCP reference |
| Operating system | macOS |

The skill was tested on one ads account that bills in USD. Other currencies, other operating systems and campaign objectives other than engagements are untested.
